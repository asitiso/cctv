# 약국 CCTV v1.0

## 실행

**`약국 CCTV.html`** 파일을 Chrome이나 Edge에서 엽니다. HTML 안에 코드, 그림, 글꼴이 함께 들어 있습니다. 상단 날짜와 시각은 현재 한국 표준시(KST)를 표시합니다. 시뮬레이션 속 직원 일정은 오전 10시 24분부터 실제 5초마다 1분씩 진행됩니다.

상단의 일시정지 버튼으로 장면을 멈출 수 있습니다. 상단의 한국 시각은 계속 현재 시각을 표시합니다. 전체 화면은 상단 버튼 또는 Esc 키로 닫을 수 있습니다. 아치형 창과 러그를 새로 그린 약국 실내 일러스트가 배경 영역 전체를 채웁니다. 기본 근무표는 기존 6명과 신규 10명을 포함합니다. 첫 화면에는 휴식 중인 2명을 포함한 근무자 14명과 우측 상단 별장의 휴무자 2명이 표시됩니다.

상단 **근무 N명**을 누르면 0~16명에서 인원 수를 고르거나 이름별로 선택할 수 있습니다. 적용한 배치는 시뮬레이션 시각을 유지한 채 바로 반영됩니다. 같은 브라우저에서는 새로고침 후에도 선택이 유지됩니다. **기본 근무표 적용**을 누르면 시각별 배치로 돌아갑니다. 별장에는 최대 2명이 나타나며, 전체 휴무 인원과 직원별 상태는 목록에서 확인할 수 있습니다.

PC에서는 왼쪽 아래 **직원 현황 16명**을 눌러 목록을 열 수 있습니다. 좁은 화면에서는 약국 아래에 목록이 기본으로 펼쳐집니다.

강아지 **모카**와 하얀 고양이 **코코**는 통로를 산책하면서 짧은 응원 메시지를 번갈아 띄웁니다. 표시 이름이 **윤희**인 직원이 약국 안에 있으면 코코는 새 길을 고를 때 70% 확률로 윤희를 따라갑니다. 상단의 일시정지 버튼으로 직원과 동물의 움직임을 함께 멈출 수 있습니다.

## 근무표 가져오기

상단의 **근무 N명**을 누르고 **근무표 가져오기**를 선택합니다. CSV나 TSV 파일을 열 수 있고, 엑셀에서 표를 복사해 붙여넣어도 됩니다. 첫 행에는 이름, 출근, 퇴근 열이 필요합니다. 예시는 다음과 같습니다.

```csv
날짜,이름,출근,퇴근,상태
2026-11-24,김한나,09:00,18:00,
2026-11-24,박별,,,휴무
```

날짜 열을 생략하면 가져오는 날의 근무표로 사용합니다. 여러 날을 넣으면 한국 시간 기준으로 그날의 행을 표시합니다. 출근과 퇴근 시간이 없는 직원은 근무 미확인으로 표시하고, 휴무는 상태 열에 명시합니다. 근무표에서 계산한 근무 시간으로 근무표상 인원을 표시합니다. 실제 출퇴근과 업무 수행 여부는 근무표로 확인할 수 없습니다. 업무가 확인되지 않은 직원은 공용 통로와 **업무 상태 미확인** 말풍선으로 표시합니다.

최대 16명의 이름을 기존 캐릭터에 대응시킵니다. 이름, 날짜, 근무 시간, 휴무 상태는 같은 브라우저에 저장되며 파일 처리에는 네트워크 연결이 필요하지 않습니다. **근무표 관리**에서 새 파일로 바꾸거나 **시뮬레이션으로 돌아가기**를 선택할 수 있습니다.

### 달력형 근무표 가져오기

엑셀이나 구글 시트에서 **일~토 요일 머리글과 한 달 전체**를 복사해 **근무표 가져오기**에 붙여넣습니다. 달력 형식이 감지되면 원본의 연도와 월을 선택합니다. 날짜 칸은 `1가온, 다온`이나 `1일 가온, 다온`처럼 날짜 번호와 쉼표로 구분한 이름을 사용합니다. 이름 없이 날짜만 적힌 날은 예정 인원이 0명으로 표시됩니다.

상단에는 **오늘 예정 N명**이 표시되고, 기본으로 펼쳐지는 **달력 명단**에서 오늘 예정자가 먼저 나옵니다. 출퇴근 시간이 없는 예정자는 근무시간 미확인으로 표시합니다. 가져온 달력은 이 브라우저에 저장되며, 시간이 포함된 근무표를 가져오면 현재 근무 인원을 그 근무표 기준으로 다시 계산합니다.

달력에서 근무시간이 일정한 직원은 화면 오른쪽 위의 **달력 근무표** 또는 **근무표 관리 → 근무시간 설정**에서 출근과 퇴근을 한 번 입력합니다. **기본 시간 → 이 달에 적용**을 누르면 직원 이름이 적힌 날에 반영됩니다. 시간대가 자정을 넘기는 경우도 처리합니다. 시간이 있는 직원 기준으로 **근무표상 인원**을 계산합니다.

특정 날만 시간이 다르면 **날짜별 예외**에서 날짜를 고르고 달라진 직원의 출퇴근 시간을 입력한 뒤 **선택한 날에 적용**을 누릅니다. 그 날짜의 시간이 기본 시간보다 우선합니다. 입력한 시간을 지우거나 **기본 시간으로**를 누르고 적용하면 해당 날짜의 기본 시간이 복원됩니다. 기본 시간도 비어 있으면 **근무 예정**으로 표시합니다.

기본 시간과 날짜별 예외는 가져온 달력과 함께 저장됩니다. 새 달력을 가져올 때는 해당 달력에 맞춰 시간을 설정합니다. 날짜별 시간이 자주 달라지면 출퇴근 열이 있는 CSV나 엑셀 표에서 정확한 시간을 가져올 수 있습니다. 업무 말풍선은 확인된 업무에 따라 표시됩니다.

## 업무 상태 가져오기

근무표를 불러온 뒤 화면 오른쪽 위의 **파일 근무표**를 누르면 업무 상태를 가져올 수 있습니다. **근무표 관리 → 업무 상태 가져오기**로도 열 수 있습니다. CSV·TSV 파일 또는 엑셀에서 복사한 표를 사용합니다.

```csv
날짜,이름,업무,시작,종료
2026-11-24,김한나,조제 중,10:00,10:20
2026-11-24,김한나,약품 포장 중,10:20,10:40
```

근무표와 같은 이름을 씁니다. 날짜를 생략하면 가져오는 날이 적용됩니다. 업무는 화면에 표시되는 상태 문구 또는 조제, 시럽, 계산, 상담, 복약지도, 재고확인, 발주, 휴식처럼 알려진 이름을 사용할 수 있습니다. 같은 직원의 업무 시간 구간이 겹치면 행을 확인할 수 있도록 가져오기 화면에 표시합니다.

근무표상 근무 시간과 업무 구간이 겹칠 때만 현재 업무를 표시합니다. 업무는 직원 현황에서 바로 볼 수 있고, 말풍선과 동작은 캐릭터가 해당 공간에 도착하면 바뀝니다. 업무 종료 시각부터는 미확인으로 표시됩니다. 업무 파일을 다시 가져오면 이전에 가져온 업무 데이터가 교체됩니다. **업무 파일 지우기**로 근무표만 표시할 수 있습니다.

## 캐릭터를 옮겨 업무 상태 지정

근무 시간에 화면 속 캐릭터를 잡으면 배치할 구역이 표시됩니다. 조제·시럽·재고·사무·상담·계산·휴식·붕어빵 중 한 곳에 놓으면 캐릭터가 통로를 따라 이동하고 도착한 뒤 새 업무 말풍선을 표시합니다. 앞쪽 붕어빵 가판대에서는 붕어빵을 종이봉투에 담습니다. 캐릭터를 한 번 누른 뒤 구역을 선택해도 됩니다. 키보드는 Tab과 Enter로 조작하며, Esc 또는 구역 바깥에 놓기로 선택을 취소할 수 있습니다.

휴무 별장에 끌어다 놓으면 **오늘은 휴무!**가 표시되고 근무 인원이 줄어듭니다. 별장을 눌러 휴무 직원 목록에서 이름을 골라 약국으로 끌어오면 다시 근무합니다. 특정 작업 구역에 놓으면 그 업무를 시작하며, 약국의 빈 바닥에 놓으면 평소 업무 구역으로 돌아갑니다. 시뮬레이션과 파일 근무표 화면에서 직접 바꾼 근무 여부는 같은 브라우저에 한국시간 자정까지 저장됩니다.

시뮬레이션에서 직접 배치한 뒤 재생 중 1분간 조작이 없으면 직원들이 번갈아 통로를 둘러봅니다. 둘러보는 직원의 말풍선에 **둘러보는 중**이 표시됩니다. 캐릭터를 다시 옮기면 즉시 직접 배치가 적용됩니다. 캐릭터를 잡는 동안과 일시정지 중에는 대기 시간이 멈춥니다.

시뮬레이션에서 휴게 공간의 **잠시 휴식 중**에는 직원들이 음료를 마시고 다과를 먹습니다. 다과 사이 간격은 표시 이름이 **정민**인 직원은 8초, 다른 직원은 12초입니다. 다과를 먹고 캐릭터 체력이 오르면 말풍선에 **체력 회복**이 잠깐 표시됩니다.

파일 근무표의 직접 지정은 현재 날짜의 근무 시간 동안 이 브라우저에 저장됩니다. 새로운 근무표나 업무 파일을 가져오면 해당 자료를 기준으로 표시합니다. 내부 시스템 연동 화면은 서버에서 받은 상태를 표시합니다.

## 직원 이름과 캐릭터 설정

**직원 현황 → 직원 이름·캐릭터 설정**을 누르거나 목록에서 직원 이름을 누릅니다. 표시 이름을 입력하고, 금테 안경을 쓴 여성 약사를 포함한 외형 19종 중에서 고를 수 있습니다. 이름을 비운 뒤 적용하면 기본 이름으로 돌아갑니다.

사용 중인 외형을 고르면 적용 전에 상대 직원 이름이 표시되고, 적용 시 두 직원의 외형이 서로 바뀝니다. **기본 외형 선택 → 적용**으로 기본 외형을 복원할 수 있습니다. 표시 이름과 외형은 이 브라우저에 저장되며, 파일 근무표의 원본 이름을 기준으로 연결됩니다.

### 표시 이름에 따른 동작

- **실장님**은 시뮬레이션에서 여러 구역을 주로 살핍니다. 휴게 공간의 간식을 채우는 간격은 재생 시간으로 최소 2분입니다. 쉬는 직원에게는 짧게 말을 건네고, 근처에서 일하는 직원은 1.2배 빠르게 동작합니다.
- **정민**은 간식 보충이 시작될 때 근무 중이고 직접 배치된 상태가 아니면 40% 확률로 잠깐 휴게 공간에 들릅니다. 간식을 한 입 먹으면 업무로 돌아갑니다.
- **국장님**은 같은 작업 공간에 직원 3명 이상이 잠시 모여 있으면 분업을 지시합니다. 국장님이 다른 공간에 있으면 직원들이 모인 공간의 이름을 부릅니다. 일부 직원은 자리가 있는 작업 공간으로 걸어가 새 업무를 시작합니다. 혜미와 혜빈이 함께 조제 중이면 두 사람은 그 자리에서 조제를 이어갑니다. 이후 캐릭터를 직접 옮기면 새 배치가 바로 적용됩니다.
- **혜미·혜빈**은 시뮬레이션에서 조제실을 자주 찾습니다. 두 사람의 작업대 변경 주기는 24초로 다른 직원의 48초보다 짧습니다. 가까이에서 함께 조제하면 작업 동작과 화면 속 확인 성공률에 각각 1.5배가 적용됩니다.
- **윤희**는 계산대에서 계산할 때 작은 검은 비닐봉지를 듭니다.

## 전달 메모

**직원 현황 → 전달 메모**에서 작성자와 받는 직원을 선택하고 최대 64자로 적습니다. 게시하면 받는 직원의 업무 상태 아래에 메모가 표시됩니다. 공간이 좁거나 캐릭터가 별장에 있으면 **메모** 표시가 뜨고, 전문은 **직원 현황**에서 볼 수 있습니다.

메모는 이 브라우저의 현황판에 저장되며 새로고침해도 게시 후 실제 시간으로 15분 동안 표시됩니다. 같은 직원에게 새로 게시하면 이전 메모가 교체됩니다. **전달 메모 → 지우기**에서 먼저 내릴 수 있습니다.

## 내부 시스템 연동

**근무 인원 → 근무표 가져오기 → 내부 시스템 연동**에서 내부 시스템이 제공하는 주소를 넣고 **연결**을 누릅니다. 파일 근무표가 열려 있으면 **근무표 관리 → 내부 시스템 연동**에서 열 수 있습니다. 연결 후에는 오른쪽 위 상태 표시에서 **지금 새로고침**, 자료 생성 시각과 **연결 해제**를 확인할 수 있습니다.

이 브라우저에 저장한 주소로 30초마다 읽기 요청을 보냅니다. 연결이 끊기거나 생성 후 90초가 지난 자료는 현재 업무로 표시하지 않습니다. 이때 마지막으로 읽은 근무표에는 **이전 근무표** 표시가 붙고, 업무는 **업무 상태 미확인**으로 바뀝니다. 연결을 해제하면 기존 파일 근무표 또는 시뮬레이션으로 돌아갑니다.

### 내부 시스템이 제공할 응답

내부 서버에서 HTTPS `GET` 요청에 `application/json`을 반환합니다. 같은 PC에서 시험할 때는 localhost HTTP도 사용할 수 있습니다. 기존 근무표와 확인된 업무의 CSV 형식을 재사용하며, 각 표에 날짜 열을 포함합니다. 업무 자료가 없을 때는 `workCsv`를 생략하거나 `null`로 보내면 됩니다. 예시의 `generatedAt`은 서버가 자료를 확인한 실제 시각을 타임존이 포함된 ISO 8601 형식으로 기록합니다. 이전 자료를 다시 제공할 때 이 시각을 새로 찍으면 표시의 유효 기간이 달라집니다.

```json
{
  "version": 1,
  "generatedAt": "2026-11-25T10:20:00+09:00",
  "rosterCsv": "날짜,이름,출근,퇴근,상태\n2026-11-25,김한나,09:00,18:00,\n2026-11-25,박별,,,휴무",
  "workCsv": "날짜,이름,업무,시작,종료\n2026-11-25,김한나,조제 중,10:00,10:30"
}
```

접근 제한이 필요한 내부 시스템은 현황판 웹 빌드와 주소를 같은 출처에 두면 기존 브라우저 인증을 사용할 수 있습니다. 출처가 다르면 응답 서버가 현황판 출처의 CORS 읽기를 허용해야 하며 브라우저 인증 정보는 전달되지 않습니다. 단일 HTML을 파일로 열면 브라우저가 `null` 출처로 요청하므로, 실제 직원 자료는 내부 웹 서버에서 열도록 구성합니다. 응답은 직원 명단, 근무표와 확인된 업무 구간만 포함하면 됩니다.

근무표에 명시된 `null`은 휴무입니다. 근무표에 직원 항목이 없으면 근무 미확인으로, 근무 중 유효한 업무 지시가 없으면 업무 상태 미확인으로 표시합니다. 근무 인원에는 휴식 중인 직원도 포함합니다. 위치가 바뀌는 업무 지시는 캐릭터가 목적지에 도착하면 행동과 말풍선에 반영됩니다.

파일에서 읽은 근무표는 실제 업무 지시와 분리합니다. 확인된 업무 파일의 시간 구간은 `DataSource.assignments`와 같은 형식으로 불러옵니다. 실행 파일은 로그인이나 외부 서비스 설정 없이 사용할 수 있습니다. 새 직원의 외형은 `staff-*.webp` 인물 파일과 직원의 `sprite`를 함께 지정합니다. 공간당 작업 자리가 한정되어 있으므로 같은 공간의 동시 인원이 늘면 `layout.ts`에서 작업 자리도 늘립니다. 가구 뒤를 지나는 캐릭터는 개별 가구 스프라이트와 캐릭터의 발 위치를 비교해 일부를 가립니다. 가구 크기는 캐릭터 설정과 독립적으로 `layout.ts`에서 조정합니다. 프레임 밖 출입문은 출퇴근할 때 화면 아래 바닥에 퍼지는 빛으로 표현합니다.

## 개발과 검증

Node.js 24 이상을 사용합니다.

```powershell
npm ci
npm run dev
npm run build
npm test
npm run test:browser
```

`npm run build`는 `dist/`에 웹 서버용 빌드를 만들고, 같은 프로젝트 폴더의 `약국 CCTV.html`을 갱신합니다. 브라우저 검증에는 설치된 Chrome을 사용합니다. Edge로 검사할 때는 `BOARD_BROWSER=msedge`에 해당하는 환경 변수를 설정합니다.

`verification/`에는 Chrome에서 촬영한 첫 화면, 근무 인원 설정, 직원 목록, 업무 변경, 모바일, 야간, 근무표와 업무 파일 가져오기, 캐릭터 외형 설정, 전달 메모, 내부 시스템 설정과 연결 상태 화면이 있습니다. `npm test`는 24시간 분량을 가속해 근무 상태와 직원 경로를 검사합니다. 브라우저 연속 재생은 PowerShell에서 `$env:BOARD_ENDURANCE_MS = '180000'`을 설정한 뒤 `npm run test:browser`로 재현할 수 있습니다.
